# Project coding preferences

- Put a brief purpose comment above every named function, method and event handler, including test helpers: `#` in Python, `//` in TypeScript/JavaScript. Explain what it does in concrete language.
- Preserve the existing compact code style. Avoid unrelated reformatting and keep functions focused.
- Use British spelling in new names and prose where appropriate.
- Run project commands in Linux/WSL. Never commit raw or processed participant data.
- Preserve the frozen cardiovascular candidate and final-check results; do not tune this version against the already-inspected final sample.
